# Game starter

This folder will hold minimal home and run scenes for a participant's own game.
The home is a real, freely walkable top-down 2D hub: it owns the map, player
spawn, NPCs, stations, and the route into a run. A shop, skill tree, or settings
panel is opened by an in-world interaction and appears as overlay UI; it does
not replace the home with a menu scene.

The run is a separate scene for the participant's chosen genre. The demo
remains separate so it can be studied or removed safely.
